한눈 리스 (Hannoon Lease) 간편 사용 메뉴얼

임대 자산 관리 프로그램

I 사용 준비

1. 환경설정 - 관련파일을 저장할 폴더 지정 (Personal)

데이터와 관련된 파일을 저장할 폴더를 지정합니다.

⚠️ 주기적인 백업 수립이 필요합니다.

2. 설정 정보 및 기본 정보 CSV 업데이트

  • 홈페이지에서 CSV 파일 양식 다운로드
  • 설정 > CSV 데이터 업로드 > 각 정보에 해당하는 CSV 파일 업로드

💡 주의 사항

• CSV 파일은 UTF-8로 인코딩 되어야 합니다.

• ID 입력이 필요한 경우 해당 데이터가 먼저 입력 또는 업로드 되어야 합니다. (회계계정과목, 기초잔액, 결제방법)

• 상세정보 항목명 설정 (직접 입력)

II 청구 실행 방법

1. 메뉴 > 청구 > 청구 실행

  • 미리 저장된 청구 템플릿으로청구 실행 버튼 클릭
  • 필요한 경우 편집을 통해 세부 품목을 수정한 후 청구 실행

2. 자동 처리 프로세스

청구 생성

청구 사건 생성 및 청구ID 발급
(확인: 메뉴 > 청구 > 청구 관리)

회계 전표 발행

임대료/관리비 등 회계 전표 발행 및 분개장 입력
(확인: 메뉴 회계 > 전표 관리)

데이터 저장

전자세금계산서/청구서 발급용 데이터 저장
(확인: 메뉴 > 청구 > 세금계산서/청구서 발급)

3. 전자 세금계산서 / 전자 청구서 발급

메뉴 > 청구 > 세금계산서 발급/청구서 발급 화면에서 발급 실행을 해야 최종 발급됩니다.

※ 전자 세금계산서/전자 청구서 발급은 유료이며 바로빌 회원 가입이 필요합니다.

III 회계 관련 정보 자동 생성

분개장 총계정 원장 임차인별 원장 미수금 장부

✨ 상기 장부들은 시스템 내에서 자동으로 생성 및 업데이트됩니다.

IV 기타 부가 기능

  • 📅 스케줄러, 업무일지
  • 💳 계좌 입출금 및 카드 승인/매입 내역 (바로빌 신청 후 이용 가능)
  • 🛠️ 기타 바로빌에서 제공하는 부가 서비스 연동 지원
