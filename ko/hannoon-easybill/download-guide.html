한눈 이지빌 다운로드 센터로 돌아가기
Microsoft Edge 스마트스크린 관련 안내

"신뢰할 수 있는지 확인합니다" 차단 해제 방법

한눈 이지빌의 모든 설치 파일은 악성코드 및 바이러스 검사를 완료한 정식 배포본입니다.
Edge 브라우저에서 아래와 같은 팝업 창이 나타나면 다음 순서대로 다운로드를 완료해 주세요.

차단 원인 안내 최신 버전 배포 직후에는 Microsoft 서버에 다운로드 평판(신뢰도)이 누적되는 기간이 필요합니다. 이에 따라 Edge 브라우저가 사용자 보호를 위해 일시적으로 다운로드를 보류하는 정상적인 반응입니다.

다운로드 보존 및 실행 단계별 가이드

1

더 보기 버튼(···)에서 [유지] 클릭

다운로드 항목 위에 마우스를 올린 후 우측의 더 보기··· 아이콘을 눌러 [유지]를 선택합니다.

2

[삭제 ∨] 버튼 우측 화살표(∨) 클릭

"열기 전에 신뢰할 수 있는지 확인합니다" 팝업창 하단 오른쪽의 [삭제 ∨] 버튼에서 오른쪽 화살표(∨) 아이콘을 클릭하세요.

클릭 위치 안내

'삭제' 글자를 클릭하면 파일이 삭제되므로, 반드시 '삭제' 글자 오른쪽에 붙어 있는 [ ∨ ] 화살표(드롭다운 콤보)를 누르셔야 메뉴가 펼쳐집니다.

3

[그래도 유지] 선택

화살표(∨)를 클릭하여 나타난 하위 메뉴에서 [그래도 유지]를 클릭하면 설치 파일 다운로드가 안전하게 완료됩니다.

파일 실행 시 "Windows의 PC 보호" 창이 뜨는 경우

다운로드한 `.exe` 설치 파일 실행 시 Windows 푸른색 안내창이 표시되면 다음과 같이 실행해 주세요.

  1. 안내문 안의 [추가 정보] 링크를 클릭합니다.
  2. 우측 하단에 생성되는 [실행] 버튼을 누르면 정상적으로 설치가 진행됩니다.
