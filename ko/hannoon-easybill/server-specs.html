SYSTEM REQUIREMENTS

한눈 서버 에디션별 권장 하드웨어 사양

동시 접속자 수 및 데이터베이스(DB) 처리 특성에 맞추어 최적화된 서버 환경 구축 가이드를 안내합니다.

Server Lite (경량형) 5인 이하

Hannoon Server Lite

내장 DB (별도 설치 없음)

소규모 팀을 위한 간편 서버로, 별도의 전용 서버 PC 없이 일반 업무용 PC에서 구동 가능합니다.

CPU Dual-Core (2코어) 이상
(Intel i3 / AMD Ryzen 3 이상)
RAM 4 GB 이상
저장장치 (SSD) 128 GB 이상의 SATA / NVMe SSD
네트워크 제한 없음
💡 특징: 업무용 PC에 함께 구동 가능하며, 백업이 용이합니다.
Server Standard (표준형) 30인 이하

Hannoon Server Standard

MariaDB(권장) / MySQL 연동

30인 이하 규모의 팀에서 다중 동시 작업 및 정기 데이터 백업을 안정적으로 지원합니다.

CPU Quad-Core (4코어) 이상
(Intel i5 / AMD Ryzen 5 이상)
RAM 8 GB ~ 16 GB
저장장치 (SSD) 256 GB 이상의 NVMe M.2 SSD
네트워크 500 Mbps ~ 1 Gbps 사내망
💡 특징: 전용 PC 권장. 외부 NAS 또는 USB 드라이브 백업을 추천합니다.
Server Enterprise 무제한 접속

Hannoon Server Enterprise

MariaDB(권장) / MySQL 대용량 연동

대규모 본지점망, 대량 트랜잭션 및 동시 접속자 수 제한 없는 최상위 서버입니다.

CPU Octa-Core (8코어 / 16스레드) 이상
(Intel i7/i9, Xeon / AMD EPYC)
RAM 32 GB 이상
저장장치 (SSD) 512 GB ~ 1 TB+ NVMe Enterprise SSD
(RAID 1 / 10 이중화 권장)
네트워크 1 Gbps 이상 사내망 또는 고속 인터넷망
💡 특징: 무정전 전원장치(UPS) 및 실시간 자동 이중화 백업 구축 권장.
