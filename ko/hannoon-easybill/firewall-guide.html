Windows 방화벽 인바운드 규칙 허용 방법

다른 컴퓨터(클라이언트)가 내 PC에 설치된 서버 프로그램에 접속할 수 있도록 특정 **포트(Port)**의 통신을 허용해 주는 5단계 초간단 안내입니다.

인바운드(Inbound) 규칙이란? 외부에서 내 컴퓨터로 들어오는 네트워크 연결 요청을 뜻합니다. 서버를 구동할 때는 외부 PC의 접속 허용을 위해 방화벽에서 포트 개방이 꼭 필요합니다.
1

고급 보안이 포함된 Windows 방화벽 실행

키보드의 Win 키 + R을 눌러 실행 창을 엽니다.

wf.msc 입력 후 [확인] 클릭
2

인바운드 규칙 메뉴 선택 및 새 규칙 만들기

좌측 창에서 [인바운드 규칙]을 클릭한 후, 오른쪽 [작업] 창에서 [새 규칙...]을 클릭합니다.

좌측: 인바운드 규칙 선택 → 우측: 새 규칙... 버튼 클릭
3

규칙 종류 및 포트 번호 지정

만들 규칙 종류로 [포트(O)]를 선택하고 [다음]을 누른 뒤, 허용할 특정 포트 번호를 입력합니다.

  • • 규칙 종류: [포트] 선택 후 [다음]
  • • 프로토콜: [TCP] 체크
  • • 특정 로컬 포트: 서버 포트 번호 입력 (예: 8080 등)
4

작업 지정 및 프로필 설정

연결 요청 시 수행할 작업으로 연결 허용을 선택하고 적용할 프로필 범위를 지정합니다.

  • • 작업: [연결 허용(A)] 선택 후 [다음]
  • • 프로필: [도메인], [개인], [공용] 모두 체크된 상태 유지 후 [다음]
5

규칙 이름 입력 및 완료

내가 어떤 포트를 허용한 것인지 구분할 수 있도록 직관적인 이름을 입력하고 [마침]을 클릭합니다.

• 이름 예시: Hannoon Server 8080 허용
• [마침]을 클릭하면 인바운드 규칙 추가 설정이 즉시 적용됩니다.
설치 및 구동 시 참고사항

• 백신 프로그램(V3, 알약, Kaspersky 등)을 별도로 사용 중인 경우, 윈도우 방화벽과 별개로 해당 백신 프로그램의 방화벽 설정에서도 동일하게 해당 포트를 허용해야 할 수 있습니다.

• 사내 공유기를 사용 중이라면 외부 망 접속 시 공유기 관리 페이지에서 **포트포워딩(Port Forwarding)** 설정이 추가로 필요할 수 있습니다.
