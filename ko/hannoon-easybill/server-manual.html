Hannoon Server 구축 및 환경설정 가이드

조직 내 다수의 사용자가 동시에 실시간 청구·전자세금계산서·회계 데이터를 공유하는 Hannoon Server의 서버 환경설정, DB(MariaDB/MySQL) 연동 및 사용자 권한 관리 절차를 안내합니다.

서버 에디션 선택 가이드 (Lite / Standard / Enterprise)

기업의 규모와 동시 접속 인원에 맞는 서버 에디션을 선택하세요. (Lite: 5인 이하 / Standard: 30인 이하 / Enterprise: 무제한)

비교 안내
간편 설치형 소규모 팀 추천

Hannoon Server Lite

별도의 외부 데이터베이스(RDBMS) 프로그램 설치 없이 원클릭으로 즉시 구동되는 경량형 서버입니다.

  • DB 설치 불필요: 내장 임베디드 데이터베이스 자동 탑재
  • 권장 접속 인원: 동시접속자 5인 이하 권장
  • 간편한 백업: 파일 1개 백업으로 전체 데이터 보관 완료
💡 5인 이하 소규모 사무실, 지점 또는 빠른 도입을 원하는 팀에 최적화
표준형 30인 이하 권장

Hannoon Server Standard

MariaDB(권장) 또는 MySQL을 설치하여 30인 이하 팀에서 실시간 데이터 동기화와 업무를 처리하는 표준 서버입니다.

  • DB 설치 필요: MariaDB(권장) 또는 MySQL 설치 필수
  • 권장 접속 인원: 동시접속자 30인 이하 권장
  • 자동 백업: 매일 지정 시간에 DB 데이터 및 파일 자동 백업
🏢 30인 이하 중소기업, 팀별 협업 환경에 최적화
엔터프라이즈형 동시접속 무제한

Hannoon Server Enterprise

MariaDB(권장) 또는 MySQL을 설치하여 동시접속자 수 제한 없이 수만 건의 트랜잭션을 안정적으로 처리합니다. 대규모 거래처 관리, 지점망 통합에 최적화되어 있습니다.

MariaDB(권장), MySQL 설치 필요

서버 시작 및 백그라운드 실행

Hannoon Server 실행 방식 및 트레이 아이콘 사용법

서버 시작 및 백그라운드 실행

  • Hannoon Server를 실행하면 백그라운드로 자동 시작됩니다.
  • 서버 실행 상태는 우측 하단 트레이 아이콘(시스템 트레이)으로 확인할 수 있습니다.
  • 메인 프로그램 창을 닫더라도 백그라운드 실행이 계속 유지됩니다.
  • 서버를 완전히 종료하려면 트레이 아이콘에서 [종료]를 선택하세요.

환경 설정 접근 방법

  • 환경 설정은 트레이 아이콘(한눈 아이콘)을 2번 클릭하면 메인 윈도우가 열립니다.
  • 메인 윈도우 폼에서 서버 설정, 백업 설정, 사용자 관리 등을 처리할 수 있습니다.
  • 트레이 아이콘 우클릭으로 간편 메뉴를 이용할 수 있습니다.
💡 트레이 아이콘이 보이지 않으면 작업 표시줄 오른쪽 끝의 숨겨진 아이콘 표시(^)를 클릭하세요.
1-A

환경설정 - 서버 설정 (Server Settings)

Hannoon Server 구동 및 네트워크 통신 필수 환경 값

1

클라이언트 접속 가능 IP 정보 확인 (Read-Only)

자동 조회 (수정 불가)

클라이언트 프로그램(HannoonEasybill Workgroup Client) 사용자가 서버에 접속할 때 입력해야 하는 서버 컴퓨터의 네트워크 IP 주소입니다. 시스템 네트워크 카드로부터 자동으로 감지되어 읽기 전용(Read-only)으로 표시됩니다.

사내망(LAN) 접속 예시: 192.168.0.50
※ 원격지 접속 시에는 공유기 포트포워딩 후 공인 IP를 사용합니다.
2

서버 Port 설정 (Service Port)

설정 변경 가능

클라이언트의 접속 요청을 수신 대기(Listen)할 통신 포트 번호를 지정합니다. 사내 보안 정책이나 타 프로그램과의 충돌 여부에 따라 포트 번호를 자유롭게 변경할 수 있습니다.

기본 포트 변경 권장 33000 (5자리 임의의 숫자, 예: 18080 등)
윈도우 방화벽 인바운드 허용 설정한 포트는 서버 PC의 [제어판 > Windows Defender 방화벽]에서 인바운드 TCP 규칙을 허용해야 외부 클라이언트 접속이 가능합니다. 방화벽 규칙 설정 방법 →
3

파일 저장 경로 (File Storage Path)

⚠️ 파일 백업 설정 필수

클라이언트 프로그램에서 서버로 업로드하는 관련 파일(참고문서, 각종 증빙 자료 등) 관련 데이터 파일이 저장되는 서버 PC의 실제 디렉토리 경로입니다.

1-B

환경설정 - DB 설정 (Standard 및 Enterprise 전용)

Standard / Enterprise

MariaDB 및 MySQL 데이터베이스 서버 연동 파라미터 구성

MariaDB / MySQL 데이터베이스 설치 Standard 및 Enterprise 에디션 구동 전 DB 프로그램 설치가 필요합니다 (MariaDB 권장).
MariaDB 공식 다운로드 MySQL 공식 다운로드
DB 주소 (Database Host)

MariaDB 또는 MySQL이 설치된 호스트 주소입니다.

기본값: 127.0.0.1 (서버 컴퓨터에 함께 설치된 경우)

※ 독립된 외부 DB 서버를 운영할 경우 해당 서버의 사내 IP 입력

DB 포트 (Database Port)

데이터베이스 통신 포트 번호입니다.

기본값: 3306

※ 보안 강화를 위해 포트를 변경한 경우 해당 변경 포트 지정 가능

DB 이름 (Database Name)

한눈 이지빌 전용 데이터베이스 스키마 이름입니다.

고정/기본값: hannoon_easybill

※ 서버 최초 실행 시 테이블 자동 생성(스키마 자동 마이그레이션)

DB 사용자 ID 및 패스워드 설정

데이터베이스 읽기/쓰기 권한을 가진 계정 정보입니다.

계정 ID: admin_user (또는 root)
패스워드: ••••••••

※ 설정 후 UI의 [DB 연결 테스트] 버튼으로 정상 통신 검증

MariaDB / MySQL 신규 데이터베이스 및 유저 생성 SQL 예시 DB 콘솔 실행 
                    CREATE DATABASE hannoon_easybill DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
                    CREATE USER 'hannoon_admin'@'%' IDENTIFIED BY '당신의안전한비밀번호';
                    GRANT ALL PRIVILEGES ON hannoon_easybill.* TO 'hannoon_admin'@'%';
                    FLUSH PRIVILEGES;
1-C

환경설정 - 백업 설정 (Backup Settings)

매일 자동 실행되는 데이터 보호 백업 구성

1

백업 시간 (Backup Time)

새벽 시간 권장

매일 자동으로 백업을 실행할 시간을 설정합니다. 업무 시간 외 새벽 시간대(예: 02:00~04:00)를 권장합니다.

권장 설정 예시: 02:00 (새벽 2시 자동 백업)
2

파일 백업 경로 (Backup Folder Path)

⚠️ 물리적 분리 권장

파일 보관 폴더(DB 데이터 및 첨부 파일)와 동기화될 백업 폴더 경로를 지정합니다. 백업 시간마다 해당 폴더로 자동 동기화됩니다.

권장 백업 대상

• 물리적으로 분리된 로컬 드라이브 (별도의 HDD/SSD) 또는

• 클라우드 드라이브 동기화 폴더 (OneDrive, Google Drive 등)

※ 서버와 동일한 드라이브는 하드웨어 장애 시 함께 손실될 수 있으므로 권장하지 않습니다.

2

사용자 추가 및 권한 관리 (User Management)

팀원별 계정 생성, 역할 배정 및 접근 보안 통제

Step 1

메뉴 이동: 설정 > 사용자 관리 > 사용자 추가

서버 관리자 화면에서 [사용자 추가] 버튼을 클릭하여 팀원의 계정을 등록합니다.

Step 2

클라이언트 배포 및 로그인 테스트

팀원의 PC에 설치된 HannoonEasybill Workgroup Client 프로그램 실행 후, 발급한 ID와 초기 비밀번호, 서버 IP/Port를 입력하여 첫 로그인을 수행합니다.

서버 접속 장애 트러블슈팅 체크리스트

Q1. 클라이언트에서 "서버에 연결할 수 없습니다." 오류가 발생합니다.

1) 서버 PC와 클라이언트 PC가 같은 공유기(동일 서브넷 네트워크)에 연결되어 있는지 확인하세요.
2) 서버 컴퓨터의 윈도우 방화벽에서 설정한 포트(Port)에 대해 TCP 인바운드가 열려있는지 점검하세요.

Q2. 서버 Standard 및 Enterprise 에디션에서 "DB 접속 설정이 올바르지 않거나 서버에 연결할 수 없습니다." 오류가 발생합니다.

1) MariaDB / MySQL 서비스(mysqld)가 Windows 서비스 관리자에서 정상 '실행 중'인지 확인하세요.
2) DB 아이디 및 DB 패스워드, DB 주소, DB 포트, 그리고 hannoon_easybill 데이터베이스가 생성되어 있는지 확인하세요.
