무료 다운로드
I

사용 준비 및 환경 설정

Personal 및 Workgroup 환경 최적화와 마스터 정보 CSV 일괄 등록

1. 환경설정 (Personal & Workgroup)

• Personal: 데이터 및 관련 파일이 저장될 로컬 파일 저장 경로를 지정합니다.
• Workgroup: 사내 Hannoon Server 컴퓨터의 서버 IP, 서버 Port, 다운로드 받는 폴더 경로를 지정하여 폐쇄형 협업 환경을 구축합니다.
• 백업 설정: 데이터 복구를 위해 파일 저장 경로 외 별도의 백업 저장 경로를 설정합니다.

Workgroup 서버 매뉴얼 지원 확인하기 →
2. 기본 정보 CSV 대량 업데이트
  • 홈페이지에서 다운로드한 표준 CSV 양식 활용
  • 경로: 설정 > CSV 데이터 업로드
  • 사업자(공급주체), 고객/임차인 정보, 청구 품목 마스터 일괄 반영
UTF-8 인코딩 필수, 선행 마스터 ID 순서 준수
II

원클릭 청구 실행 및 자동 처리 프로세스

템플릿 기반 청구 생성, 전표 자동 발행 및 전자세금계산서 발급 연동

Step 1

청구 실행 (Billing Execution)

경로: 메뉴 > 청구 > 청구 실행

미리 등록된 정기 청구 템플릿과 청구명을 확인한 후 [청구 실행] 버튼을 클릭합니다. 세부 수량, 단가, 할인액을 즉시 편집할 수 있습니다.

Step 2

원클릭 5대 자동화 처리 결과

전자 세금계산서 발급

바로빌 연동, 국세청 즉시 전송

전자 청구서 발급

이메일/알림톡 발송

회계 전표 자동 발행

분개장 차변/대변 자동 기록

주요부 자동 생성

분개장 & 총계정원장 실시간 생성

보조부 자동 생성

거래처별 원장 & 미수금 장부

회계 관련 장부 실시간 자동 생성

분개장

차변/대변 자동 분개 기록

총계정 원장

계정과목별 누적 합계 집계

고객/거래처별 원장

업체별 청구 및 수납 관리

미수금 장부

실시간 미수 채권 감시

IV

다수 공급주체 관리 및 N:N 상호 교차 청구 시스템

복잡한 다중 사업자 및 얽혀 있는 거래 구조도 단 하나의 단일 솔루션으로 관리

1. 단일 프로그램 내 다수 공급주체(사업자) 통합 관리

프로그램을 여러 번 설치하거나 세션을 개별로 전환할 필요 없이, 단 하나의 프로그램 내에서 다수의 공급주체(사업자/공급자) 명의를 생성하고 일괄 관리할 수 있습니다.

  • • 계열사, 지점, 복수 법인/사업자 명의별 고객 마스터 및 청구 독립 관리
  • • 사업자별 매출 전표, 장부, 세금계산서 발급 이력 개별 및 통합 집계
2. N:N 복합 비즈니스 구조 상호 교차 청구 지원

공급주체와 공급받는주체가 일대다(1:N)가 아닌 다대다(N:N)의 복합관계에 있는 비지니스 환경에서도 상호 맞춤형 정산 및 교차 청구가 가능합니다.

  • • 프랜차이즈, 지입 운송망, 컨소시엄, 공동 임대 등 교차 정산 구조 지원
  • • 주고받는 청구/입금/출금 거래에 대해 차변/대변 전표 및 교차 세금계산서 원스톱 연동
V

한눈 이지빌 차별화 시스템 (보안 · 백업 · 업데이트)

핵심 업무 자동화를 뒷받침하는 강력한 보안 관리 및 무중단 운영 지원

1. 독립형 보안 체계

고객 개인 정보, 회사 재무관련 정보, 회사 영업 정보를 외부 서버 사용으로 인한 유출 우려 없이 기업 자체에서 철저히 관리할 수 있습니다.

  • • [개인용]: 사용자 컴퓨터(PC)에 모든 데이터가 독립적으로 안전하게 저장됨
  • • [워크그룹]: 한눈 서버를 이용해 회사 내 폐쇄형 네트워크(사내 인트라넷) 환경을 완벽 구축
2. 자동 백업 시스템

데이터 유지보수를 위한 별도의 외주 비용이 발생하지 않으며, 손쉬운 설정만으로 안전하게 복구 대책을 마련합니다.

  • • 환경설정에서 지정한 백업 경로(별도 드라이브, 클라우드 가상 드라이브, NAS 등)로 주기적 자동 백업
  • • [개인용]: 프로그램 종료 시 자동 백업
  • • [워크그룹]: 서버에서 매일 지정한 정시에 자동 백업
3. 자동 업데이트

세법 변경, 기능 개선 및 전자세금계산서 연동 모듈을 언제나 최신 상태로 유지할 수 있습니다.

  • • 프로그램 시작 시 신규 업데이트 버전 자동 체크
  • • 클릭 한 번으로 간편 패치 및 신규 기능 즉시 반영
