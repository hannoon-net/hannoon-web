WHY HANNOON EASYBILL

왜 '한눈 이지빌'을 선택해야 할까요?

복잡한 청구와 회계 업무를 쉽고 간단하게 해결함은 물론, 차별화된 보안과 강력한 관리 시스템을 제공합니다.

원클릭 청구 및 전표 발행

저장된 템플릿으로 매월 돌아오는 정기 청구를 단 한 번의 클릭으로 완료합니다. 청구 사건 생성과 동시에 회계 분개장 전표가 자동 작성됩니다.

청구 실행 프로세스 보기

국세청 전자세금계산서 연동

국세청 공인 발급대행기관인 바로빌(Barobill)과 공식 연동되어, 별도의 홈택스 로그인 없이 프로그램 내에서 대량으로 즉시 전송됩니다.

4대 복식부기 회계 장부 자동화

수기 입력 없이 분개장, 총계정 원장, 고객/임차인별 원장, 미수금 장부가 실시간 생성되어 누락 없는 채권 회수와 결산이 가능합니다.

회계 자동화 기능 보기

한눈 이지빌의 차별화된 장점

자체 데이터 관리, 외주 비용 부담 없는 자동 백업, 항상 최신을 유지하는 자동 업데이트

1. 보안상의 압도적 유리함

개인 정보, 회사 재무관련 정보, 회사 영업 정보 등을 외부 유출 걱정 없이 자체 관리합니다.

  • [개인용] 사용자 컴퓨터에 모든 데이터가 안전하게 저장됨
  • [워크그룹] 한눈 서버를 이용해 회사 내 폐쇄형 네트워크(사내 망) 환경 구축

2. 자동 백업 시스템

데이터 유지보수를 위한 외주 비용이 발생하지 않습니다.

  • 환경설정에서 지정한 백업 경로에 주기적으로 자동 백업
  • [개인용] 프로그램 종료 시 자동 백업
  • [워크그룹] 서버에서 매일 지정한 시간에 자동 백업

3. 원스톱 자동 업데이트

항상 최신 기능을 빠르게 반영할 수 있습니다.

  • 프로그램 시작 시 신규 업데이트 버전을 자동으로 체크
  • 클릭 한 번으로 최신 패치 간편 설치 권유 및 가이드
투명한 무료 정책 안내

한눈 이지빌 프로그램은 무료입니다

프로그램 자체의 모든 핵심 기능(청구 관리, 전표 분개, 회계 장부, 일정 관리 등)은 무료로 이용하실 수 있습니다.
단, 전자세금계산서, 전자문서, 문자/팩스 등 외부 발급대행기관(바로빌) 서비스는 국세청 전송망 이용에 따른 바로빌 포인트를 충전하여 이용 건당 실비로 차감됩니다.

PRODUCT EDITIONS

사용 환경에 맞는 에디션을 선택하세요

개인용 데스크탑부터 다수 직원이 협업하는 사내 인트라넷 서버 환경까지 완벽히 지원합니다. Workgroup 서버는 Lite / Standard / Enterprise 에디션으로 구성됩니다.

Standard 무료 프로그램

Personal (개인용 에디션)

1인 사업자, 소규모 임대인, 프리랜서 관리자에게 최적화된 독립 실행형 데스크탑 프로그램입니다.

  • 단일 PC 환경 즉시 실행 (사용자 컴퓨터 데이터 저장)
  • 다수 사업자 및 거래처별 통합 관리
  • 회계 장부 자동 생성 및 전자세금계산서 연동
  • 프로그램 종료 시 자동 백업 지원
Personal 에디션 다운로드 개인용 매뉴얼 확인 →
Workgroup 에디션 사내 네트워크 무료 구축

Workgroup (워크그룹 에디션)

기업 및 조직 내에서 다수의 팀원이 실시간으로 동일 데이터를 동시 열람하고 처리하는 사내 폐쇄형 네트워크 인트라넷 솔루션입니다.

  • Client: HannoonEasybill 클라이언트 프로그램
  • 보안 구축: 회사 내 폐쇄형 망 구축으로 중요 정보 보안 강화
  • 정기 백업: 서버에서 매일 지정 시간에 자동 백업
  • Server 라인업: Server Lite / Standard / Enterprise
