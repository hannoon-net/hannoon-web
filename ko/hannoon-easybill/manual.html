한눈 이지빌 프로그램 사용 가이드

환경 설정부터 CSV 대량 업로드, 정기 청구 실행, 전자세금계산서 발행 및 회계 장부 확인까지 쉽게 따라 할 수 있는 가이드입니다.

운영 시 필수 주의 사항 및 데이터 규칙

  • CSV 파일 인코딩 표준: 대량 업로드용 CSV 파일은 한글 깨짐 방지를 위해 반드시 UTF-8로 인코딩되어야 합니다.
  • 데이터 입력 선행 순서: ID 입력이 필요한 참조 항목은 해당 마스터 데이터가 시스템에 먼저 등록되어야 청구 등록 시 오류가 발생하지 않습니다.

I 사용 준비 및 환경 설정

1. 환경설정 - 개인용 에디션 (Personal)

단일 PC

메뉴 경로: 설정 > 환경설정에서 아래 3가지 주요 항목을 설정합니다.

파일 저장 경로 설정

데이터베이스 및 첨부 파일이 보관될 로컬 컴퓨터 저장 경로를 지정합니다.

프로그램 사용 용도

UI 표시를 위해 사용 용도에 맞는 비즈니스 업종(부동산 임대, 렌탈, 지입 관리 등)을 선택합니다.

파일 백업 경로

프로그램 종료 시 최신 데이터가 자동으로 저장될 안전한 외장/클라우드 드라이브 경로를 설정합니다.

2. 환경설정 - 워크그룹 에디션 (Workgroup Client)

네트워크 협업

사내 Hannoon Server와 연결하기 위해 클라이언트 프로그램에서 아래 4가지 항목을 설정합니다.

서버 IP 주소

접속할 사내 서버의 고정 IP 주소를 입력합니다.

서버 Port

지정된 5자리 포트 번호를 입력합니다.

다운로드 경로

서버에서 수신된 문서를 다운로드할 로컬 폴더를 지정합니다.

프로그램 사용 용도

업종별(임대, 렌탈, 지입 등) 환경 구성을 선택합니다.

참고: 워크그룹 에디션의 백업 시간 및 파일 백업 경로는 클라이언트가 아닌 서버(Hannoon Server)에서 직접 구성됩니다.
서버 매뉴얼 바로가기

3. 설정 정보 및 기본 정보 CSV 업로드

  • 표준 CSV 양식을 다운로드하여 사업자/고객 정보, 청구 템플릿, 계정과목 등을 작성합니다.
  • 메뉴 경로: 설정 > CSV 데이터 업로드에서 파일 일괄 업로드
표준 CSV 양식 다운로드 (.zip) 대량 업로드용 기본 양식 세트 파일
CSV 업로드 가이드 CSV 파일 작성 방법 및 인코딩 안내

II 청구 실행 방법

1. 메뉴 > 청구 > 청구 실행

미리 등록된 청구 템플릿과 청구명을 확인하고 [청구 실행] 버튼을 클릭합니다.

2. 원클릭 3대 자동 처리 프로세스

청구 사건 생성

청구ID 발급 및 데이터베이스 기록

회계 전표 자동 발행

복식부기 분개장 자동 기록

발급 대기 데이터 생성

전자세금계산서 국세청 전송용 규격 생성

바로빌 가입 안내 전자세금계산서 연동 발행을 위한 바로빌 회원가입 및 API 연동 방법
서비스 단가 안내 (팝업) 전자세금계산서 및 전자문서 발급 건당 포인트 차감 단가표
