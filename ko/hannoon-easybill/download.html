프로그램 라인업 (Personal & Workgroup)

기업의 규모와 네트워크 환경에 맞는 버전을 선택하여 설치하세요.

단일 PC / 1인용 무료 프로그램

Personal 에디션

한눈 이지빌 개인용 프로그램

1인 사업자, 프리랜서 및 소규모 관리자에게 최적화된 독립 실행형 데스크탑 프로그램입니다.

  • 내장 로컬 DB (설정 불필요)
  • 단일 PC 즉시 실행 및 백업
  • 전자세금계산서 원클릭 발행
  • 복식부기 4대 장부 자동 생성
Windows 10/11 (64-bit)
SHA-256 해시값 확인
Workgroup / 팀원용 무료 프로그램

Workgroup Client

Workgroup 에디션 클라이언트 프로그램

사내 인트라넷 Hannoon Server에 접속하여 다수의 팀원이 실시간으로 동일 데이터를 공동 처리합니다. (Workgroup 에디션 전용)

  • 중앙 서버 실시간 데이터 동기화
  • 팀원별 계정 로그인 및 권한 적용
  • 다중 사용자 동시 청구 및 전표 입력
  • 서버 IP/Port 간편 설정 지원
Windows 10/11 (64-bit)
SHA-256 해시값 확인
서버 (경량형) 5인 이하

Server Lite

DB 별도 설치 불필요 (간편 서버)

외부 데이터베이스 설치 없이 원클릭으로 구동되며, 5인 이하 소규모 팀에 최적화된 고효율 서버입니다.

  • DB 프로그램 별도 설치 필요 없음
  • 동시접속자 5인 이하 권장
  • 원클릭 서버 실행 및 IP 자동 감지
  • 단일 파일 백업으로 손쉬운 관리
Windows / Windows Server
SHA-256 해시값 확인
서버 (표준형) 30인 이하

Server Standard

MariaDB(권장) / MySQL 설치 필요

MariaDB 또는 MySQL과 연동하여 30인 이하 규모의 팀에서 안정적으로 다중 동시 작업을 처리합니다.

  • MariaDB(권장), MySQL 설치 필요
  • 동시접속자 30인 이하 권장
  • 사용자 권한 분리 및 접근 통제
  • 지정 시간 매일 자동 백업 지원
서버 구축 매뉴얼 확인 →
SHA-256 해시값 확인

Hannoon Server Enterprise

대규모 지점망, 수백 명의 팀원 협업 및 대량 트랜잭션을 처리하는 최상위 엔터프라이즈 서버입니다.
MariaDB(권장) 또는 MySQL 설치 후 동시접속자 수 제한 없이 안전하게 운영할 수 있습니다.

  • MariaDB(권장), MySQL 설치 필요
  • 동시접속자 무제한
  • 고속 인덱싱 & 대용량 데이터 처리
  • 매일 정시 자동 백업 & 동기화
