Q 도입 & 비용 한눈 이지빌 프로그램은 정말 평생 무료인가요? 숨겨진 유료 요금이 있나요?
한눈 이지빌은 설치 대수, 거래처 수, 청구 건수, 사용 기간에 아무런 제한이 없는 평생 100% 무료 소프트웨어입니다.

소프트웨어 도입비나 월 정기 구독료가 전혀 없으며, 국세청 전자세금계산서 전송, 카카오 알림톡/SMS 문자 발송, 계좌 거래내역 자동 조회와 같이 외부 통신망(바로빌)을 이용할 때 소요되는 최소 실비 포인트(세금계산서 건당 198P 등) 외에는 어떠한 추가 비용도 발생하지 않습니다.

Q 청구 & 세금계산서 엑셀로 관리하던 임대료 및 정기 청구 장부, 프로그램으로 어떻게 자동 전환하나요?
기존에 수기나 엑셀로 관리하던 고객 명단과 청구 내역을 표준 CSV 파일 일괄 업로드 기능을 통해 몇 번의 클릭만으로 손쉽게 이전할 수 있습니다.

한눈 이지빌 다운로드 센터에서 제공하는 표준 CSV 업로드 양식(.zip)을 내려받아 상호, 사업자번호, 대표자명, 이메일, 기본 청구 금액 등을 입력한 후 프로그램 내 [기본 정보 CSV 대량 업데이트] 메뉴에서 불러오면 즉시 데이터베이스로 자동 전환됩니다.
CSV 파일 작성 가이드 확인하기다운로드 센터에서 샘플 양식 받기
Q 청구 & 세금계산서 국세청 홈택스 직접 발행 vs 바로빌 API 연동 자동 발행의 차이점과 비용은?
국세청 홈택스는 무료이지만, 매월 수십~수백 건의 거래처마다 로그인하여 일일이 공급가액, 품목, 세액, 이메일을 수기로 입력해야 하므로 막대한 시간과 오입력 위험이 따릅니다.

반면 한눈 이지빌의 바로빌 API 연동을 이용하면 프로그램에 저장된 템플릿을 통해 100건 이상의 전자세금계산서를 단 3초 만에 국세청으로 일괄 즉시 전송할 수 있습니다. 발행 비용은 건당 198P(약 198원) 수준으로, 실무자의 수십 시간의 야근과 인건비를 획기적으로 절감해 줍니다.

Q 회계 & 장부 복식부기 회계 원리를 전혀 몰라도 분개장과 미수금 장부가 자동으로 생성되나요?
네! 한눈 이지빌의 가장 강력한 차별점 중 하나입니다. 사용자가 복식부기 차변/대변 원리를 몰라도 단순히 '청구서 발행' 버튼만 누르면 프로그램 내부 회계 엔진이 자동으로 올바른 분개 전표를 생성합니다.

발행과 동시에 분개장, 총계정원장, 거래처별원장, 미수금장부 4대 핵심 장부에 실시간 반영되며, 고객사에서 입금되었을 때 '입금 처리'만 체크해 주면 미수금 잔액이 즉시 차감 정리됩니다.

Q 산업별 실무 화물·중장비 지입차주 월 관리비 및 보험료 세금계산서(N:N 상호 청구) 발행 시 주의사항은?
지입/운송 비즈니스는 운송사가 차주에게 관리비/보험료를 청구(매출)하고, 동시에 차주가 운송사에 운송용역을 청구(매입)하는 공급자-공급받는자가 교차되는 N:N 상호 거래 구조를 가집니다.

한눈 이지빌은 업계 유일 N:N 상호 교차 청구 기능을 탑재하여 양방향 세금계산서와 정산서를 원클릭으로 상계 정산 처리할 수 있습니다. 지입료(과세)와 보험료/공제금(비과세/예수금) 항목을 분리 등록해 두시면 실수령액이 자동 산출됩니다.

Q 서버 & 보안 클라우드가 아닌 사내 PC나 폐쇄망 서버(Workgroup)에서도 다수가 함께 쓸 수 있나요?
네, 한눈 이지빌은 기업의 영업 기밀과 고객 재무 데이터 보호를 최우선으로 여깁니다. 해외 외부 클라우드에 데이터를 올리지 않고, 사내 폐쇄망 인트라넷 LAN 환경에서 여러 사용자가 동시 접속하여 실시간 협업할 수 있는 Workgroup Server & Client 시스템을 제공합니다.

소규모 팀을 위한 DB 미설치형 Server Lite(5인 이하)부터, 수십~수백 명이 접속하는 Server Standard(MariaDB 연동), Enterprise까지 모두 무료로 제공됩니다.
Hannoon Server 구축 매뉴얼서버 하드웨어 권장 사양
Q 도입 & 비용 Personal(개인용)과 Workgroup(서버/클라이언트) 중 어떤 에디션을 설치해야 하나요?
관리자 1명이 단일 PC에서 독립적으로 청구 및 장부를 관리하고자 하신다면 Personal 에디션을 설치하시면 됩니다. 별도 서버 설정 없이 설치 즉시 바로 사용 가능합니다.

반면 경리팀, 영업팀, 관리부 등 2명 이상의 직원이 사내 네트워크에서 데이터를 실시간 공유하고 동시 작업해야 한다면 사내 PC 1대에 Hannoon Server를 설치하고 각 실무자 PC에 Workgroup Client를 설치하여 연결하시면 됩니다.

Q 서버 & 보안 컴퓨터를 교체하거나 포맷할 때 기존 데이터는 어떻게 백업하고 복구하나요?
한눈 이지빌은 자체 자동 백업 시스템을 내장하고 있어, 사용자가 지정한 보조 드라이브나 USB, 외장하드 경로에 주기적으로 데이터 백업본을 자동 생성합니다.

PC를 교체하거나 재설치할 때는 새 PC에 프로그램을 설치한 후 기존 백업 파일(DB 파일)을 동일한 데이터 폴더에 복사해 넣기만 하면 이전 데이터가 100% 완벽히 복원됩니다.
간편 사용 매뉴얼 백업 안내
Q 청구 & 세금계산서 사업자등록번호가 없는 개인 고객(원룸 월세, 학원생 등)에게는 어떤 증빙을 발행하나요?
개인 임차인이나 일반 소비자에게는 전자세금계산서 대신 국세청 현금영수증(소득공제용/지출증빙용)을 바로빌 연동을 통해 프로그램 내에서 직접 발행할 수 있습니다.

고객의 휴대폰 번호나 주민등록번호를 등록해 두시면 세금계산서와 마찬가지로 원클릭으로 국세청에 즉시 등록되며 알림 문자도 자동 전송됩니다.
