홈 솔루션 소개 주요 기능 소개

주요 기능 소개

청구 실행부터 자동 회계 장부 생성 및 부가 서비스까지 시스템의 핵심 기능을 안내해 드립니다.

운영 시 필수 주의 사항 및 데이터 규칙

  • CSV 파일 인코딩 표준: 모든 업로드용 CSV 파일은 반드시 utf-8로 인코딩 되어야 합니다.
  • 데이터 입력 선행 조건: ID 입력이 필요한 항목(회계계정과목, 기초잔액, 결제방법 등)은 해당 데이터가 시스템에 먼저 입력 또는 업로드되어야 오류가 발생하지 않습니다.
  • 상세정보 항목명 설정은 직접 입력 방식으로 처리됩니다.
I

사용 준비 및 환경 설정

데이터 저장 폴더 지정 및 마스터 정보 CSV 업데이트

1. 환경설정 (Personal)

데이터와 관련된 파일을 안전하게 저장할 폴더를 지정합니다. 안정적인 시스템 운영을 위해 주기적인 백업 수립이 반드시 필요합니다.

정기 백업 권장 영역
2. 기본 정보 CSV 업데이트
  • 홈페이지에서 CSV 파일 양식 다운로드
  • 경로: 설정 > CSV 데이터 업로드
  • 각 항목별 마스터 정보 파일 일괄 업로드
UTF-8 인코딩 필수 적용
II

청구 실행 및 자동 처리 프로세스

템플릿 기반 청구 실행, 전표 발행 및 세금계산서 발급

Step 1

청구 실행

경로: 메뉴 > 청구 > 청구 실행

미리 저장된 청구 템플릿과 청구명을 확인/입력 후 청구 실행 버튼을 클릭합니다. 필요한 경우 세부 품목을 편집한 후 실행할 수 있습니다.

Step 2

자동 처리 결과

청구 사건 생성

고유 청구ID 생성
(확인: 메뉴 > 청구 > 청구 관리)

회계 전표 발행

임대료/관리비 부과 전표 및 분개장 입력
(확인: 메뉴 회계 > 전표 관리)

발급 데이터 저장

세금계산서/청구서 데이터 연동
(확인: 메뉴 > 청구 > 세금계산서 발급/청구서 발급)

Step 3

전자 세금계산서 / 전자 청구서 최종 발급

경로: 메뉴 > 청구 > 세금계산서 발급/청구서 발급

해당 화면에서 발급 실행을 해야 최종 발급이 완료됩니다.

전자 세금계산서/청구서 발급은 유료 서비스이며 바로빌 회원 가입이 필요합니다.
